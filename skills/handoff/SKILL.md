---
name: handoff
description: 将当前对话压缩为一份交接文档，让另一个 Agent 能接着工作。
argument-hint: "下一次会话将用于什么？"
disable-model-invocation: true
---

编写一份交接文档，概括当前对话，使一个新 Agent 能继续工作。保存到用户操作系统的临时目录（`$TMPDIR`，未设置时使用 `/tmp`；Windows 使用 `%TEMP%`），不要保存在当前工作区。

文档中须包含「建议使用的技能」一节，列明下一个 Agent 应通过 Skill 工具调用哪些技能。

不要重复其他工件（规格、计划、ADR、工单、提交、差异）中已有的内容，改为用路径或 URL 引用它们。

隐去所有敏感信息，例如 API 密钥、密码或个人身份信息。

如果用户传入了参数，将其视为下一次会话关注内容的说明，并据此调整文档。
