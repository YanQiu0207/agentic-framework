# 高级初始化

仅在主 Skill 已查询确认 `knowledge-advanced` 启用后读取。先确认用户需要的模式，再执行对应章节；通用不覆盖规则与项目入口验证不变。

## SVN

- Git + SVN：本地使用 Git，正式提交由用户执行 SVN；纯 SVN 不引入 Git。
- 运行 `svn info` 核实工作副本。纯 SVN 若不存在工作副本则停止，提示用户先建立工作副本后重跑；不得用 `svnadmin create` 或复制方式擅自建仓库。Git + SVN 未接入时记录补做项。
- 读取后合并 `svn:ignore`，不覆盖现有值。根级忽略 `.agentic-framework/`、`.DS_Store`、`Thumbs.db`；Git + SVN 另加 `.git` 和 `.svn/`。纯 SVN 的 `.svn/` 不追踪。
- `svn:ignore` 逐目录生效：`.claude/` 下单独合并 `settings.local.json`，不把嵌套路径写入根忽略。Git + SVN 的 `.gitignore` 另加 `.svn/`。
- 纯 SVN 只逐路径 `svn add` 本次产物，不执行 `svn commit`；报告「已加入，未提交」。Git + SVN 只本地 Git 提交，不 push 或 SVN 提交。
- 普通 SVN Native Delivery 可以执行；命中 Runtime 升级条件时停止，建议 Git 隔离工作区，不降低审查风险。

## 外置知识正文

1. 用户提供绝对路径；解析项目根、外部目录和公共库真实路径，外部私有正文不得与项目根或公共库重叠，也不得位于公共库内。
2. 目录不存在可创建；空目录可使用；非空则展示清单并停止，经用户明确确认才复用，仍不得覆盖文件。项目 `openspec` 已存在或是任意链接时不替换。
3. 确认保护方式：项目 Git、独立 Git 或明确备份系统。无版本管理且无备份时停止，并说明丢失风险。
4. 确认恢复方案，记录外部绝对路径、链接类型和新机器重建步骤，再创建骨架及目录符号链接。Windows 无符号链接权限时，解释后经用户同意才使用目录联接；禁止静默复制。
5. 单独询问是否跟踪链接本身，不擅自加入 `.gitignore`。在 `AGENTS.md` 记录正文位置、保护与恢复步骤。
6. 必须从 `<project>/openspec/` 读取三个索引，并核实链接类型和真实目标。失效时报告失败，不新建同名目录掩盖。外置正文不在工作树内时，分别报告独立提交或备份状态，不冒充已随项目提交。

## 公共知识库接线

仅当用户要求接线时单独确认；不与外置正文绑定。

1. 从已有配置取得公共库路径并展示确认；没有有效路径时请求绝对路径。
2. 验证根 `index.md` 可读，且与外置私有正文不重叠。
3. 只在 `AGENTS.md` 缺少公共库章节时追加入口与边界，不覆盖已有章节，不修改全局配置。
4. 边界须明确：只保存用户确认、脱敏泛化后的知识；项目专属知识和未确认候选不能写入公共库；公共知识只是参考，冲突须报告双方证据。

报告仅列本次启用模式的工作副本、正文保护、链接恢复、接线、提交结果；未完成项不能报告成功。
