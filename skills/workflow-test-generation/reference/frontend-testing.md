# 前端测试场景

## 选择边界

- 组件测试验证组件状态、事件与渲染；优先复用项目现有组件测试工具。
- 前端隔离测试允许通过 `page.route()` 替换 API，验证页面交互与错误状态；报告中声明替换边界，不作为真实前后端打通的证据。
- 浏览器 E2E 从用户操作到最终业务结果验证受测系统的真实前后端协作。外部第三方可使用沙箱或替身，但须记录边界；不得替换正在验证的内部关键调用。

## 选择场景

| 条件 | 测试点 | 结果断言 |
| --- | --- | --- |
| 有核心业务操作 | 进入、填写、提交、刷新或重新进入 | 最终业务状态正确，不只验证提示弹窗 |
| 有异步加载 | 加载中、空数据、失败、重试、过期响应 | 状态切换正确，旧响应不覆盖新结果 |
| 有输入约束 | 空值、长度边界、非法输入、重复提交 | 校验符合契约，不产生重复业务副作用 |
| 有身份或权限 | 未登录、会话失效、角色不足 | 页面行为正确；后端授权另由 API 或系统测试验证 |
| 有路由与分页 | 深链接、刷新、前进后退、分页边界 | 路由、筛选条件与显示数据一致 |
| 有适配或可访问性要求 | 目标视口、键盘操作、焦点与可访问名称 | 满足项目已确认的 UI 和可访问性要求 |

正常、边界、异常场景拆成聚焦用例，不要求每个用例混合执行全部场景。

## Playwright 执行约定

- 复用项目现有测试目录、命名和运行器配置；无约定时使用 `<feature>.e2e.ts`，放在对应 feature 目录。
- 使用 `page.getByRole`／`page.getByText` 等语义定位器，禁止 CSS 选择器。
- 使用 `expect(locator).toBeVisible()` 等自动等待断言，不使用固定 `sleep`。
- 隔离测试按场景替换 API；全链路 E2E 准备独立测试数据，并验证最终持久化结果或可观察业务结果。
- 失败时保留相关截图、追踪和日志，报告运行范围及替换依赖，不把隔离测试通过写成全链路通过。
