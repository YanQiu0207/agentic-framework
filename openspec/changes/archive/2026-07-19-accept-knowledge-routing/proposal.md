# Proposal：验收统一知识路由

## 1. 背景

统一知识管理实施完成后，需要用当前真实项目验证 Change Delta 能映射到长期 Specs。

## 2. 目标

- 验证安装器 Shared Core 约束已进入长期项目知识。

### 2.1 非目标

- 不改变安装器运行行为。

## 3. 需求概览

- `project-init` 与 `project-knowledge` 必须由 Production 和 Tooling 共用。

## 4. 验收标准

- Change Delta、长期目标、安装器代码和 Profile 测试结论一致。

## 5. 知识影响

- 更新安装器模块的人工约束。
