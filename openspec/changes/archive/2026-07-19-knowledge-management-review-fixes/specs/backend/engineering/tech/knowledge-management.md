# 知识管理审查修复 Delta

## 新增要求

1. 迁移计划生成器必须兼容 Python 3.12+，不得使用 `PurePath.relative_to()` 的多段位置参数。
2. 公共知识校验器必须区分合同违规（退出码 `1`）与读取、编码或遍历错误（退出码 `2`）。
3. Fast-Path 交付门必须获得结构化知识影响结论；无影响时必须提供理由。
4. 自动生成知识的 `meta.yaml` 必须进入来源新鲜度检查；检查结果为非阻塞告警。
5. 项目私有边界的机器验收只证明公共索引及其 Validator 不会桥接其他项目正文；Agent 主动检索范围由操作 Skill 人工合同约束，不宣称文件系统安全隔离。

## 修改要求

1. 历史文档保留原生命周期状态，通过目录级 `Superseded` 入口和逐文件迁移映射停止写入。
2. 本地 Markdown 链接解析必须由共享 Helper 提供统一语义。
