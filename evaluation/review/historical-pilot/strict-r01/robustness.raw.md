### P2：右侧为嵌套组合时，将其依赖矩阵全部置为 1，导致独立输出被误判为相关

- **位置**：`r01/astropy/modeling/separable.py:245`
- **触发条件**：调用 `separability_matrix(Shift(1) & (Shift(2) & Shift(3)))`，且组合使用第 306—309 行的递归计算分支。
- **根因**：`_separable()` 将右子树计算为矩阵后传入 `_cstack()`。第 244—245 行虽然按右子树尺寸分配空间，却将整个右下区块填成 `1`，没有复制 `right` 的实际值。相对地，左子树矩阵在第 240 行被原样复制。
- **具体影响**：右侧两个独立的 `Shift` 本应形成单位矩阵，但嵌入外层时变成全 1 的 `2 × 2` 区块。最终相关矩阵由预期的三阶单位矩阵变为：
  ```text
  True   False  False
  False  True   True
  False  True   True
  ```
  `is_separable()` 的具体调用路径在第 60—62 行对矩阵逐行求和，因此会进一步将后两个独立输出误判为不可分离。仅改变 `&` 的嵌套位置便破坏依赖关系。
- **证据与级别**：第 78—81 行明确规定独立输出的非对角元素应为 `False`；第 307—309 行证明矩阵确实由递归调用传入。该问题在特定合法嵌套结构下静默返回错误结果，评为 **P2**。
- **最小修复方向**：第 245 行赋值使用 `right` 而非标量 `1`，并补充右侧嵌套组合的回归测试。
